LCS — Tabulation

A bottom-up iterative approach that fills a 2D table dp[i][j] representing the LCS length of the first i characters of string1 and first j characters of string2.

Goal

Find the length of the longest common subsequence by building up from empty substrings.

Algorithm Flow

1. Create a 2D table dp[m+1][n+1] initialized to 0
2. Iterate over each character i of string1 from 1 to m
3. For each character j of string2 from 1 to n:
    - If characters match — take dp[i-1][j-1] and add 1
    - If they don't match — take the max of dp[i-1][j] and dp[i][j-1]
4. Answer is at dp[m][n]

Example

String1 = ABCD, String2 = ACBD

        A   C   B   D
    0   0   0   0   0
A   0   1   1   1   1
B   0   1   1   2   2
C   0   1   2   2   2
D   0   1   2   2   3

Answer: dp[4][4] = 3.
