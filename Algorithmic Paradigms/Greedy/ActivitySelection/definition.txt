Activity Selection Problem

A greedy algorithm where you select the maximum number of non-overlapping activities, each having a start time and end time.

Goal

Maximize the number of activities that can be performed without any two overlapping.

Algorithm Flow

1. Sort activities by end time in ascending order
2. Always select the first activity
3. Iterate through the remaining activities — if the current activity's start time is greater than or equal to the last selected activity's end time, select it
4. Return the count or list of selected activities

Example

Capacity n = 4 activities
Activity    Start   End
A           1       3
B           2       5
C           4       6
D           6       8
Sorted by end time: A → B → C → D
Select A (end: 3), skip B (start 2 < 3, overlaps), select C (start 4 ≥ 3), select D (start 6 ≥ 6)
Selected: A, C, D
Total: 3 activities
