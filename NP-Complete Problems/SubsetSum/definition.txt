Subset Sum Problem

A decision problem where you have a set of integers and a target sum, and you need to determine if any subset of the set adds up to exactly the target sum.

Goal

Return true if a subset exists that sums to exactly the target value T, false otherwise.

Best Algorithm Design Approach

Dynamic Programming (tabulation) — build a 2D boolean table where each cell represents whether a subset of the first i elements can sum to exactly s.

Algorithm Flow

1. Create a 2D boolean table of size (n+1) × (T+1) initialized to false
2. Set the entire first column to true — a sum of 0 is always achievable with an empty subset
3. Iterate over each element i from 1 to n
4. For each sum s from 0 to T:
    - If the current element exceeds s, carry over the value from the row above
    - Otherwise take the OR of carrying over from above, or reaching s - element[i] from the previous row
5. Answer is at dp[n][T]

Example

Set = {3, 1, 4, 2}, Target = 6

    0   1   2   3   4   5   6
-   T   F   F   F   F   F   F
3   T   F   F   T   F   F   F
1   T   T   F   T   T   F   F
4   T   T   F   T   T   F   F
2   T   T   T   T   T   T   T

Answer: dp[4][6] = true.
