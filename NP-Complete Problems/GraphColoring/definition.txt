Graph Coloring Problem

A problem where you assign colors to vertices of a graph such that no two adjacent vertices (connected by an edge) share the same color, using at most k colors.

Goal

Determine if a graph can be colored with at most k colors, and if so, find a valid coloring.

Best Algorithm Design Approach

Backtracking — try assigning a color to each vertex one at a time, checking for conflicts, and backtracking when no valid color exists for the current vertex.

Algorithm Flow

1. Start at vertex 0
2. Try assigning each color from 1 to k to the current vertex
3. Check if the color is safe — no adjacent vertex has the same color
4. If safe, assign the color and recurse on the next vertex
5. If recursion fails, unassign the color (backtrack) and try the next color
6. If no color works, return false to trigger backtracking on the previous vertex
7. If all vertices are colored, return true

Example
4 vertices, k = 3 colors, edges: (0,1), (0,2), (1,2), (1,3), (2,3)

    0   1   2   3
0   0   1   1   0
1   1   0   1   1
2   1   1   0   1
3   0   1   1   0

Vertex 0: try color 1 → no adjacent vertices colored yet, safe → assign color 1
Vertex 1: try color 1 → adjacent to vertex 0 (color 1), conflict → try color 2 → safe → assign color 2
Vertex 2: try color 1 → adjacent to vertex 0 (color 1), conflict → try color 2 → adjacent to vertex 1 (color 2), conflict → try color 3 → safe → assign color 3
Vertex 3: try color 1 → adjacent to vertex 1 (color 2) and vertex 2 (color 3), safe → assign color 1
All vertices colored → return true

Answer: Vertex 0 = color 1, Vertex 1 = color 2, Vertex 2 = color 3, Vertex 3 = color 1.
